AI Project Workspace + Project State

문서의 변화가 프로젝트 상태와 다음 업무로 이어지는 방향을 보여줍니다. 이력·메일·상태 갱신은 준비된 시나리오로 시연합니다.

제품 방향 시연
구현 범위와 시연 범위 자세히 보기 +

문서 데모는 실제 서식을 보존하거나 재현한 PDF 미리보기와 가상 내용을 사용합니다. 기본 문서 시나리오는 47개, 별도 메일 첨부는 2개이며, Project State 시연에는 가상 수정본이 추가됩니다. 파일 감지와 화면 조작, 문서 열기와 근거 이동은 실제로 동작합니다. 분석·요청·회신·상태 변화는 준비된 데모 데이터이며 실제 AI 판단이나 메일 송수신이 아닙니다. 실제 AI 분석, HWP/HWPX 전체 처리, 메일 계정 연동과 공사 중 지속적인 상태 관리는 이후 개발합니다. 원본 문서를 변경하지 않으며, 전문적·법적 최종 판단은 사람이 합니다.
