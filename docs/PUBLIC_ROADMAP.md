# AIARC Public Roadmap

AIARC는 큰 비전을 한 번에 구현하지 않습니다. 실제 현장자료와 사용자 검증을 통과한 범위부터 넓혀갑니다.

## Phase 0 — Prototype

준공 단계의 문서 정리와 누락 검토를 짧고 명확하게 시연합니다.

```text
현장 폴더 / ZIP
→ 분석
→ 문서 분류
→ 확보 / 누락 / 확인 필요 / 중복
→ 전체 정리
→ 근거 확인
```

## Phase 1 — Usable Alpha

한 현장에서 계속 켜두고 사용할 수 있는 제품으로 발전합니다.

- 현장 프로젝트 유지
- 폴더 변화 감지
- 이메일 첨부파일 유입
- HWP/HWPX 연동
- AI 판단 근거 확인
- 안전한 되돌리기

## Phase 2 — Continuous Document Workflow

준공 직전 한 번 쓰는 도구가 아니라 공사 중부터 문서의 상태와 최신본을 지속 관리하는 제품으로 확장합니다.

- 품질·자재 문서
- 자재승인
- 검측
- 설계변경
- 도면 revision
- 누락·회신 상태

## Phase 3 — Construction Document AX

여러 현장과 팀에서 문서 흐름을 관리하고, 착공부터 준공까지 문서의 생성·승인·변경·최종 제출을 연결합니다.

## Long-term vision

장기적으로 AIARC가 다루려는 공통 흐름은 다음과 같습니다.

```text
수집
→ 이해
→ 관계 연결
→ 생성
→ 검토
→ 승인·변경
→ 전달
→ 회신 추적
→ 버전 관리
→ 최종 제출
```

국내 건축·건설의 실제 업무환경을 충분히 깊게 해결한 뒤에만 더 넓은 시장 확장을 검토합니다.

상세 단계별 구현계획과 내부 기술 로드맵은 비공개 개발 저장소에서 관리합니다.
